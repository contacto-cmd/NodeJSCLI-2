🔥 FLUJO TÉCNICO

1️⃣ INGEST

Recibe:
	•	Texto
	•	JSON
	•	HTTP POST

Normaliza el input.

⸻

2️⃣ PARSER

Convierte texto en intención estructurada:

"deploy staging"

Se vuelve:

{
  intent: "deploy",
  env: "staging"
}


⸻

3️⃣ DECISION ENGINE

Aquí vive la “pseudo inteligencia”.

Reglas:
	•	Si deploy → prioridad alta
	•	Si audit → consulta
	•	Si amy → conversación

Aquí puedes meter scoring, prioridad, etc.

⸻

4️⃣ EXECUTION

Llama al módulo correspondiente.

Router interno limpio.

⸻

5️⃣ MEMORY

Guarda:
	•	Último comando
	•	Estado
	•	Logs
	•	Historial

Por ahora puede ser un simple objeto en memoria.

Enterprise luego → Redis o DB.

⸻

🧬 CÓDIGO BASE SIMPLIFICADO

server.js

const express = require("express")
const app = express()
app.use(express.json())

const ingest = require("./eagi/ingest")

app.post("/command", async (req, res) => {
    const result = await ingest(req.body.command)
    res.json(result)
})

app.listen(3000, () => console.log("EAGI Pipeline Running"))


⸻

ingest.js

const parser = require("./parser")
const decision = require("./decision")

module.exports = async function(command) {
    const parsed = parser(command)
    const result = await decision(parsed)
    return result
}


⸻

decision.js

const execution = require("./execution")

module.exports = async function(parsed) {
    return execution(parsed)
}


⸻

execution.js

const deploy = require("../modules/deploy")
const audit = require("../modules/audit")
const amy = require("../modules/amy")

module.exports = async function(parsed) {
    switch(parsed.intent) {
        case "deploy":
            return deploy(parsed)
        case "audit":
            return audit()
        default:
            return amy(parsed)
    }
}
